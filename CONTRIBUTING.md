# Contributing to QuickSRT

Small, focused pull requests are welcome.

1. Fork and clone `https://github.com/abgitdev/QuickSRT.git`.
2. Create a short-lived branch from the current `main` branch.
3. Keep the change focused; do not add generated apps, models, virtual environments, FFmpeg binaries, local builds, audits, logs, media, or subtitles.
4. Run the Python and Swift tests documented in [`README.md`](README.md).
5. Update documentation and tests when behavior changes, then open a pull request describing the change and verification performed.

Never include secrets or personal data in code, fixtures, screenshots, logs, commit messages, or pull-request text. Use synthetic fixtures. Report security issues through [`SECURITY.md`](SECURITY.md), not a public issue.

By submitting a contribution, you agree that it may be distributed under the repository's [`LICENSE`](LICENSE).
